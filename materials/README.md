# Materials

Reusable materials, shaders, and node groups. _Empty for now; see the roadmap in the main README._

One folder per material:

```
materials/<material-name>/
├── <material-name>.blend    # Git LFS
├── preview.jpg
└── notes.md                 # inputs, outputs, how it works
```

Use in Blender: **File → Append** → pick the `.blend` → open `Material` or `NodeTree` → select the item.

Naming: materials `MAT_Name`, node groups `NG_Name`.
